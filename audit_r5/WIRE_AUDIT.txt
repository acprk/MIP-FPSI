Findings
  * No send of X, Y, x-bits, y-bits, distances, matched indices, or the ground truth. No debug path sends plaintext.
  * Ground truth (net_bench.cpp 104-138, main.cpp 75-113) is computed locally by the harness from both sets
    (each harness process generates/reads both X and Y) and is never passed to fpsiSender/fpsiReceiver or to the socket.
    It uses a pigeonhole index over delta+1 contiguous blocks + mip::hamming (popcount), not the protocol's tables.
  * noU branch: no recv(U)/send(U); all sizes depend on (m, n, B, public); program size n*T (not n*T*U).
  * or_deliver.cpp (otFPSI baseline adapter): X is neither deduplicated nor shuffled before delivery, so the
    order of R's output equals the sender's file order (baseline only; not the MIP protocol).
  * Test hook MIP_INJECT_CUCKOO_FAIL (HamCpsi.cpp 153) is in library code; it only forces local resampling.
